# tauri-plugin-eisenhower

On crates.io as `tauri-plugin-eisenhower` (`tauri-plugin-eisenhower = "0.1"`
in the app's `src-tauri/Cargo.toml`); its client on npm is
`@frodobaggins.jr/eisenhower-tauri`.

Eisenhower's Tauri 2 plugin: documents (a board, a timeline, a gantt chart, a
todo list, as `@eisenhower/model` writes them) read and written on disk, with
a hash guard so a save never overwrites a file another program changed. Its
typed client and storage adapter are
[`@eisenhower/tauri`](../../packages/tauri/README.md).

```rust
tauri::Builder::default()
    .plugin(tauri_plugin_eisenhower::init())
```

and `"eisenhower:default"` in the window's capability. The commands, their
arguments, answers and error codes are in
[the Tauri integration](../../docs/features/tauri.md).

The commands are thin: each passes its arguments to a function of the crate
(`read_document`, `write_document`), on a blocking thread. `build.rs` lists
the commands; Tauri writes their permissions to `permissions/autogenerated`
and `permissions/default.toml` allows them all. Tests are in `tests/unit` and
use Tauri's mock runtime.
